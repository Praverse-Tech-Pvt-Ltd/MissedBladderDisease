# Missed Bladder Disease Website

Standalone Next.js site for the Missed Bladder Disease educational hub.

## Setup

```bash
pnpm install
```

Create `.env.local` from `.env.example` and configure:

- `RESEND_API_KEY`
- `RESEND_FROM_EMAIL`
- `CONTACT_EMAIL`

## Development

```bash
pnpm dev
```

Local URL: `http://localhost:3001`

## Build

```bash
pnpm build
```

## Deployment

Deploy this directory as its own Vercel project.

Set domain: `missedbladder.com`.
